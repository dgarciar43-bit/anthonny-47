# anthonny 47Ejecutar el programa:
Inicia el proyecto en Visual Studio y presiona F5 para ejecutar.
Seleccionar una opción:
En el menú principal escribe el número de la opción que deseas utilizar.
Agregar empleado:
Selecciona la opción 1 e ingresa el nombre, salario base y horas extra. El programa asignará automáticamente un ID y calculará el pago total.
Listar empleados:
Selecciona la opción 2 para mostrar todos los empleados registrados y el total de la nómina.
Buscar empleado:
Selecciona la opción 3 y escribe el nombre o parte del nombre del empleado que deseas buscar.
Calcular factorial:
Selecciona la opción 4 e ingresa un número entero mayor o igual a cero. El programa calculará su factorial mediante una función recursiva.
Salir:
Selecciona la opción 5 para cerrar el programa.
